HR Data Analysis Using Excel
Project Overview
This project analyzes Human Resources (HR) data using Microsoft Excel to uncover workforce trends, employee demographics, and key HR insights.

Identify trends in employee attrition and retention.
Explore employee satisfaction and other HR metrics, where available.
Build an interactive Excel dashboard to support data-driven decision-making.
